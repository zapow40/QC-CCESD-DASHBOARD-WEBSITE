GITHUB PAGES DEPLOYMENT — IMPORTANT

This package is already laid out for GitHub Pages.

REQUIRED:
1. Extract the ZIP.
2. Upload the CONTENTS of this folder to the GitHub repository root.
   Do NOT upload the ZIP itself.
   Do NOT create a QC-CCESD-DASHBOARD-WEBSITE subfolder inside the repository.
3. Confirm that index.html is directly visible at:
   <repository root>/index.html
4. In GitHub:
   Settings → Pages
   Build and deployment → Source: Deploy from a branch
   Branch: main (or the branch you actually uploaded to)
   Folder: / (root)
5. Save and wait for the Pages deployment to finish.
6. Open:
   https://zapow40.github.io/QC-CCESD-DASHBOARD-WEBSITE/

If GitHub Pages is set to /docs, either change it to /(root), or put ALL
contents of this package inside /docs instead.

The Google Apps Script backend is separate and is not changed by this package.
